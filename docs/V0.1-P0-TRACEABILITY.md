# v0.1 P0 Failure-Mode Traceability

**As of:** 2026-08-17  
**Scope:** P0 rows in `FAILURE-MODE-MATRIX.md`  
**Rule:** `PASS` requires executable evidence or an enforced architectural
absence. `PARTIAL` and `OPEN` prevent a stable `v0.1.0` unless RFC-0002 is
amended with an explicit exclusion.

| ID | State | Control/evidence | Remaining work |
|---|---|---|---|

| F-005 | PASS (excluded) | trace/export persistence is absent | becomes OPEN if recorder/export enters release scope |

## Stable release blockers from this table

1. F-001: egress-deny CI proof.
2. F-006: automated repository secret/PII policy.
3. F-008: bounded parser/evaluator fuzz evidence.
4. F-010: decide whether L2 promotion is in or out of v0.1.
5. F-087: structured logging/redaction policy.
6. F-100: align public repository metadata with implemented capabilities.

Excluded rows become active blockers immediately if their corresponding code
path enters the release branch.
