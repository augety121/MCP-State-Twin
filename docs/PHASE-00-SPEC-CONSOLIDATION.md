# Phase 0: Specification and Claim Consolidation

- **Target:** current integration cycle
- **Entry:** competing normative/proposal documents exist
- **Exit:** one authority tree and evidence-backed public claims

## Scope

- establish the authority order in DOCS-GOVERNANCE;
- adopt RFC-0001 revision 3 and the release split in ADR-0021;
- mark `00-*` through `33-*` as non-normative proposal material;
- maintain requirement, claim, compatibility and decision ledgers;
- distinguish public main, candidate worktree and roadmap capability;
- remove the circular v0.1 provider gate;
- eliminate unsupported universal/AGI capability wording.

## Exclusions

No proposal becomes implemented merely because this phase documents it. This
phase does not provide live provider evidence, L2 fidelity or remote-production
security.

## Exit evidence

- no two active documents claim final authority for the same release gate;
- every public implementation claim has a CLM ID;
- every accepted invariant has a traceability row;
- README translations agree on maturity and exclusions;
- link and terminology checks pass;
- docs name exact versions rather than inheriting compatibility transitively.
